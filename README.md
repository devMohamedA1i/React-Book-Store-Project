# React Book Store (Redux Toolkit CRUD)

A React book catalog and inventory app implementing full CRUD state management with Redux Toolkit.

**Live Demo:** [redux-toolkit-crud-app.vercel.app](https://redux-toolkit-crud-app.vercel.app)

## Tech Stack

- CSS, Redux Toolkit, Axios, React, React Router, Redux, JavaScript

## Structure

```text
├── public/
├── src/
```

## Getting Started

```bash
git clone https://github.com/devMohamedA1i/React-Book-Store-Project.git
cd React-Book-Store-Project
npm install
npm run start
```
